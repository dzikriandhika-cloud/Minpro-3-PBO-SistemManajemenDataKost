## Deskripsi Program
Sistem Manajemen Data Kost merupakan program berbasis Java yang dibuat untuk membantu pengelolaan data penghuni kost. Program dijalankan melalui console dan menerapkan konsep Pemrograman Berorientasi Objek (PBO).

## Fitur Program
Program memiliki beberapa fitur utama, yaitu:
1. Menambah data penghuni
2. Menampilkan seluruh data penghuni
3. Mencari data penghuni berdasarkan ID
4. Mengubah data penghuni
5. Menghapus data penghuni
6. Keluar dari program

## Data Penghuni
Data yang dikelola dalam program meliputi:
- ID penghuni
- Nama
- Nomor HP
- Nomor kamar
- Jenis penghuni
- NIM dan universitas untuk mahasiswa
- Data khusus karyawan untuk penghuni berstatus karyawan

## Struktur Program
Program dibagi menjadi beberapa package agar lebih terstruktur:
- Controller
- Model
- View

Pada bagian Model terdapat class yang digunakan untuk mengelola data penghuni, mahasiswa, dan karyawan.
